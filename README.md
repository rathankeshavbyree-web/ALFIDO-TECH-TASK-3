# VRBAV - User Directory Application

A modern, responsive web application for managing user directories with search, create, and explore functionality. Built with vanilla HTML, CSS, and JavaScript featuring a premium burnt orange glass theme design.

## Features

- **Search Users**: Find users quickly by name with real-time search functionality
- **Add Users**: Create new user entries with name, email, and city information
- **User Directory**: Display all users in an elegant card-based layout
- **Local Storage**: Persistent data storage using browser localStorage
- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Premium burnt orange glass theme with smooth animations

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with gradients, animations, and glass morphism effects
- **JavaScript (ES6+)**: Vanilla JavaScript for all functionality
- **Google Fonts**: Poppins font family for typography
- **LocalStorage API**: Client-side data persistence

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. Clone or download the project files
2. Open `index.html` in your web browser
3. The application is ready to use

### Usage

1. **Search Users**: Type in the search bar to filter users by name
2. **Add New User**: Fill out the form with name, email, and city, then click "Add User"
3. **View Directory**: Browse all users in the card-based grid layout

## API Integration

The application is designed to work with localStorage by default but includes API integration capabilities. It can fetch user data from external APIs and store it locally for offline access.
